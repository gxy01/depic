# Depic VS Code 扩展

在 VS Code 中可视化 JS/TS 项目依赖图。

[English](./README.md) | 中文

## 特性

- **依赖图** — WebGL 交互式图，支持搜索和子包筛选
- **循环依赖检测** — 发现并可视化循环依赖
- **依赖方分析** — 查看谁依赖了当前文件
- **统计信息** — 文件/边/外部模块数量
- **Monorepo 支持** — 按子包筛选

## 命令

- `Depic: Show Dependency Graph` — 在 Webview 中打开交互式依赖图
- `Depic: Check Circular Dependencies` — 在输出面板中查看循环依赖
- `Depic: Show Dependents of Current File` — 查看谁导入了当前文件
- `Depic: Show Dependency Statistics` — 统计摘要
