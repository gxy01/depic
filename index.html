depic

Explore dependencies. Guard architecture. Explain change impact.

GitHub npm Live Demo

Use Cases

Explore a codebase

Search module relationships in graph, tree, and file views through the Web UI or VS Code.

Guard architecture

Detect cycles, inspect dependents, trace symbols, and understand monorepo package boundaries.

Review a change

Combine the official Agent Skill with deterministic graph analysis to find affected entries and packages.
