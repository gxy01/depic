# Depic VS Code Extension

Interactive dependency graph visualization for VS Code.

English | [中文](./README.zh-CN.md)

## Features

- **Dependency Graph** — WebGL-powered interactive graph with search and package filtering
- **Circular Dependency Detection** — Find and visualize cycles
- **Dependents Analysis** — See who depends on the current file
- **Statistics** — File/edge/external module counts
- **Monorepo Support** — Filter by sub-package
- **Structured Webview Data** — Graph data stays inert and message replies remain structured

## Commands

- `Depic: Show Dependency Graph` — Open interactive graph in webview
- `Depic: Check Circular Dependencies` — Find cycles in output panel
- `Depic: Show Dependents of Current File` — Who imports this file
- `Depic: Show Dependency Statistics` — Summary statistics
